# Рисованные персонажи

Одобренные пользователем портреты в более естественной рисованной стилистике.
Семь прозрачных WebP-листов, по пять эмоций слева направо:
`neutral`, `smile`, `joy`, `worry`, `stern`.

Персонажи: главная героиня, главный герой, Ирина Петровна (куратор),
Вероника Александровна (директор техникума), Алина Дмитриевна (HR-менеджер),
Наталья Сергеевна (директор компании), Индира Ринатовна (наставник).
Иллюстрации созданы генерацией изображений и согласованы до подключения.
Внешность наставника уточнена по предоставленному пользователем фото;
исходная фотография в сборку не включена.

Параметры кадров находятся в `src/render/portrait-frames.ts`, отрисовка —
в `src/render/illustrated-portraits.ts`. Эмоции выбираются SVG-окном без
повторной загрузки изображения. Отдельные подписи имени и роли выводит UI.
Существующие параметры SVG сохранены как запасной вариант для новых персонажей.
