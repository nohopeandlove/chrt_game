# Фоны для сцен

`crt-campus.webp` — рисованная интерпретация главного входа Челябинского
радиотехнического техникума для сцены выпускного. Иллюстрация создана с помощью
генерации изображений по двум фотографиям, предоставленным пользователем,
и приведена к плоской графической стилистике игры. Фотографии не включаются
в игровую сборку и не используются в качестве текстуры. Сезон — лето.
Иллюстрация оптимизирована в WebP и подключается через сборку Vite.

Место использования: `prologue`, фон `crt-campus`.

`hero-room.webp` — новая рисованная ночная комната с ноутбуком, созданная по
композиции предоставленного скриншота. Используется в `portfolio` и `resume`.
Свечение лампы и экрана, звёзды и пар добавлены отдельными SVG-слоями.
У ЧРТ медленно падает праздничное конфетти. Все эффекты отключаются
настройкой «Без анимации» и системным `prefers-reduced-motion`.
