# Методическое сопровождение «Я — специалист»

## Назначение и ожидаемые результаты

Сюжетный тренажёр карьерной грамотности для студентов СПО и выпускников,
готовящихся искать первую работу. Преподаватель адаптирует содержание к специальности,
возрасту и образовательной программе группы. Четыре специальности в игре — учебные
группы, а не утверждённый перечень специальностей техникума.

После занятия обучающийся должен уметь:

- представить учебный проект через задачу, собственный вклад и результат;
- сопоставить требования вакансии с навыками и заметить запросы опасных данных;
- обосновать решение на собеседовании, назвать условия договора для проверки;
- выбрать безопасный способ действий в незнакомой рабочей задаче.

Это формирующее оценивание. Баллы и достижения не являются квалификационной,
психологической диагностикой или основанием для решений о найме.

## Сценарий занятия: ориентир 45–60 минут

1. 5 минут: обсудить опыт поиска работы, цель и правила безопасности.
2. 5 минут: вводный экран и необязательная входная диагностика из трёх вопросов.
3. 25–35 минут: индивидуальная работа или работа в паре. Таймера нет;
   допускаются перерывы, помощь преподавателя и большее время.
4. 5 минут: итоговая диагностика, журнал, выбор следующего действия.
5. 5–10 минут: обсуждение двух решений и их последствий. При необходимости
   продолжить прохождение на следующем занятии в том же браузере.

Это план занятия, а не измеренная длительность прохождения. Перед занятием
преподаватель проходит игру самостоятельно и оценивает время для своей группы.

## Обратная связь и оценивание

Входная и итоговая диагностика используют одинаковые три ситуации: мошенничество,
резюме без опыта, условия договора. После проверки показываются выбранные ответы,
правильные варианты и объяснения. Сравнивайте результаты только если пройдены обе
диагностики. Повторение вопросов даёт эффект запоминания; разница баллов не доказывает
эффективность игры и не покрывает все заявленные умения.

Кабинет показывает проценты по заданиям, действия, ошибки, рекомендации, открытые этапы, входной/итоговый балл и все завершённые попытки
тестового и мини-теста по трудовым отношениям. Открытый этап не означает освоенный
навык. Перезапуск текущей главы может повторно провести задание; попытки не скрываются.
Кабинет позволяет скачать JSON/CSV без имени, резюме и контактных данных; ФИО/код и группа добавляются только по отдельному выбору студента. Автоматической
отправки преподавателю нет; обмен результатом — добровольный и по правилам учреждения.

Рекомендуемая рубрика наблюдения, которую заполняет преподаватель отдельно:

| Умение | Требует поддержки | Выполняет с подсказкой | Самостоятельно |
|---|---|---|---|
| Резюме | Перечисляет общие качества | Называет проект | Связывает вклад с результатом |
| Вакансии | Не видит риск | Находит по подсказке | Называет риск и способ проверки |
| Договор | Смотрит только на оплату | Называет часть условий | Объясняет условия и гарантии |
| Рабочая задача | Действует наугад | Просит готовое решение | Проверяет документацию и уточняет задачу |

Обсуждение после игры: «Почему этот вариант безопаснее?», «Какая информация нужна
для решения?», «Как действовать, если ситуация в жизни отличается от сценария?».
Итог — одно конкретное действие: дополнить резюме, проверить работодателя,
сформулировать вопросы о договоре. Проверить его выполнение на следующем занятии.

## Реалистичность и границы

Компании, вакансии, суммы и события — учебные примеры. «Секретное слово» тренирует
чтение инструкции, но не является нормой найма. Проходной результат 100% в игровом
тестовом — условность, а не общий стандарт работодателей. После отказа разрешены
новые попытки. Шкалы уверенности и репутации — игровые индикаторы, не оценка личности.

Правовые фрагменты необходимо проверять по действующей редакции ТК РФ и ГК РФ
перед внедрением, в частности ТК РФ ст. 15, 19.1, 56, 57, 67, 70 и 71; ГК РФ ст. 702
и 779. Официальный источник публикации правовых актов: https://pravo.gov.ru/ .
Название договора не заменяет анализ фактических отношений. Игра не даёт юридической
консультации; профильные задания не подтверждают профессиональную квалификацию.
Актуальность всех правовых формулировок экспертом в рамках этой доработки не подтверждена.

## Универсальный дизайн и персональные данные

- Клавиатура: Tab/Shift+Tab, Enter; для реплик Enter/пробел, для диалоговых выборов цифры.
- Настройки на каждом экране: крупный текст, контраст, отключение анимации.
  Учитывается системный prefers-reduced-motion. Короткие звуковые сигналы включаются отдельно и не несут уникальной учебной информации; звуковых заданий нет.
- Реплики объявляются скринридеру целиком, а не посимвольно. Правильность ответа
  обозначена текстом и не зависит только от цвета. Журнал открывается как модальный
  диалог с удержанием фокуса; Escape возвращает в игру.
- Нет лимита времени. Можно обсуждать задания устно, работать в паре или увеличить
  длительность занятия. Требуется дополнительная проверка с целевыми пользователями
  и реальными вспомогательными технологиями; соответствие WCAG не сертифицировано.
- Имя допускает псевдоним. В учебном резюме используйте вымышленные данные.
  Сохранение находится в localStorage этого браузера. Очистка данных удаляет его;
  при запрете записи выводится предупреждение. Продолжение — с начала текущей главы.
- Встроенной серверной аналитики нет. Внешний Google Fonts запрашивает шрифт;
  при его недоступности используется системный. Для закрытой сети можно заблокировать
  внешние шрифты без потери основной функциональности; полную офлайн-работу надо
  проверить в выбранном способе размещения. Сервис-воркера нет.

## Внедрение и апробация

1. Проверить примеры, специальности и нормативные формулировки с преподавателями.
2. Запустить через Docker по README или разместить `dist/` на статическом сервере.
   Для скачивания зависимостей и образов при первой сборке нужен Интернет.
3. Проверить на устройствах группы: Chromium/Edge/Firefox/Safari, Android/iOS,
   клавиатура, увеличение и скринридер. Поддержка конкретных платформ подтверждается
   протоколом проверки, а не наличием адаптивной вёрстки.
4. Провести пилот с небольшой группой по правилам учреждения. Отдельно записать
   число завершивших, затруднения, время и результаты диагностики без лишних данных.
5. Зафиксировать версию игры, исправления, решение о внедрении и ответственного.

Пилот с обучающимися, юридическая экспертиза, проверка всех браузеров и заключение
о педагогической эффективности пока не проведены. Эти сведения нельзя заявлять как готовые.

## Поддержка и редактирование

Сюжет: `content/scenes/`, вакансии: `content/vacancies.json`, тестовые задания:
`content/tests.json`, диагностика и учебные инструменты: `src/learning.ts`.

## Проверки этой версии

Проверено автоматически в Chromium/Linux: начало игры и вводный экран; входная
диагностика 3/3; сохранение и продолжение; настройки; открытие журнала с клавиатуры;
выгрузка без имени/резюме; успешная попытка тестового и разбор; ошибочный ответ
мини-теста; итоговая диагностика и отчёт; экран 390 × 844 с крупным текстом;
предупреждение при запрете localStorage и возможность продолжить игру.
Проверка контента и TypeScript: `npm run check`. Production-сборка: `npm run build`.
Полное прохождение всех веток и матрица реальных устройств в эти проверки не входят.

Повторяемый браузерный smoke-тест: `tools/learning-smoke.cjs`. Он работает против
Vite dev-сервера (использует импорты модулей для проверки специализированных экранов),
а не против production-контейнера. Playwright — внешний инструмент проверки,
в зависимости приложения не добавлен. Пример для Linux с системным Chromium:

```bash
# В одном терминале из корня проекта:
npm run dev -- --port 5174

# В другом терминале из корня проекта:
npm install --prefix /tmp/chrt-browser --cache /tmp/chrt-npm-cache --no-audit --no-fund playwright@1.64.1
PLAYWRIGHT_MODULE=/tmp/chrt-browser/node_modules/playwright BROWSER_EXECUTABLE=/usr/bin/chromium node tools/learning-smoke.cjs
```

При необходимости в изолированном контейнере без поддержки Chromium sandbox добавьте
`BROWSER_NO_SANDBOX=1`. `GAME_TEST_URL` задаёт другой адрес Vite. Без
`BROWSER_EXECUTABLE` Playwright использует свой установленный браузер.

## Кэш браузера и удаление прогресса

Сохранённое прохождение находится в localStorage, отдельно от HTTP-кэша файлов.
Очистка только кэшированных изображений/файлов не удаляет прогресс. В стартовом меню
показана сохранённая глава и кнопка «Удалить сохранение». Она удаляет только
сохранённую игру (включая её локальные ФИО/код и группу), сохраняя настройки звука
и доступности. При запрете удаления браузером выводится сообщение, а не ложное
подтверждение. Кнопка «Продолжить» появляется только при наличии учебного прогресса;
одного ввода псевдонима недостаточно. Пройденная входная диагностика считается прогрессом.

Геометрия реплик проверяется `tools/layout-save-smoke.cjs`: подпись, текст и «Дальше»
должны лежать внутри рамки на desktop, узком и низком окне, с обычным/крупным текстом.
Тот же тест проверяет новый вход, начальное автосохранение без прогресса, очистку
HTTP-кэша и явное удаление сохранения. Запуск с Playwright — аналогично остальным
smoke-тестам выше; используется Chromium/CDP.
