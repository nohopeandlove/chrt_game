# Я — специалист

Образовательная сюжетная игра о пути от выпускного до первого рабочего дня:
портфолио, резюме, вакансии, тестовое, собеседование, договор и первая рабочая задача.
Проект ГБПОУ «Челябинский радиотехнический техникум».
Автор сценария — Ганеева Индира Ринатовна.

## Запуск на компьютере

Установите и запустите Docker Desktop, откройте терминал в корне репозитория:

```bash
docker compose up --build -d
```

Игра: http://localhost:8080 . Отдельный кабинет преподавателя: http://localhost:8080/teacher/ .
Студенты не загружают и не передают файлы. Результаты автоматически сохраняются
на сервере; преподаватель видит их после входа. У студента остаётся кабинет своего
прогресса, без импорта, экспорта и вкладки преподавателя.

При первом входе преподавателя получите одноразовый код:

```bash
docker compose exec game node server/manage.mjs setup-code
```

Введите код на странице `/teacher/`, придумайте логин и пароль от 12 символов.
После настройки код уничтожается. Общего предустановленного пароля нет.
CSV для Excel доступен только на странице преподавателя после входа.

Обновление:

```bash
git pull
docker compose up --build -d
```

База SQLite хранится в постоянном Docker volume `game-data`. Обычный перезапуск,
пересборка и `docker compose down` сохраняют её. **`docker compose down -v` удалит
базу**. Не меняйте имя Compose-проекта/папки без переноса данных. Для остановки:
`docker compose stop`.

## Размещение для группы

Все студенты должны открывать один адрес общего сервера. Отдельный Docker
на каждом компьютере создаёт отдельные базы, а не общий журнал.

Нужен хостинг с Docker или Node.js 24 и постоянным диском. GitHub Pages и загрузка
только папки `dist/` больше не обеспечивают работу отчётов. Инструкция для VPS,
домена и автоматического HTTPS: [DEPLOY.md](DEPLOY.md).
Хостинг и домен в рамках доработки не приобретены; публичная ссылка не опубликована.

## Разработка без Docker

Node.js 24. После `npm ci` и `npm run build`:

```bash
npm start
```

Это запускает игру и API на http://localhost:3000 и кабинет на /teacher/.
Данные по умолчанию находятся в игнорируемой папке `data/`.
Для разработки с обновлением интерфейса держите `npm start` в одном терминале,
а `npm run dev` — в другом: Vite перенаправляет `/api` на порт 3000.
Порт задаётся переменной `PORT`, каталог базы — `DATA_DIR`. На хостинге каталог
базы должен переживать обновления и быть доступным для записи пользователю процесса.

Проверки:

```bash
npm run check
npm run build
node tools/server-smoke.mjs
```

Браузерные тесты с внешним Playwright: `tools/learning-smoke.cjs`,
`tools/reporting-smoke.cjs`, `tools/layout-save-smoke.cjs` (dev-сервер) и
`tools/server-browser-smoke.mjs` (сам запускает временный production-сервер).
Инструкции установки инструмента — в методичке.

## Обучение и аналитика

- [Методические рекомендации](docs/METHODICAL.md)
- [Формулы оценивания и серверная аналитика](docs/ANALYTICS.md)
- [Матрица конкурсных критериев](docs/CRITERIA.md)

Входная и итоговая диагностика содержат разные ситуации по общим темам.
Тестовое сразу объясняет ответы. Кабинет показывает проценты, ошибки, действия,
рекомендации и историю попыток. Крупный текст, контраст и отключение анимации
доступны в верхней панели. Звуки выключены по умолчанию.

Прогресс позиции в игре хранится в браузере; отчёты — на сервере. Очистка кэша
не удаляет браузерное сохранение. «Удалить сохранение» удаляет локальное прохождение,
но **не удаляет уже переданные преподавателю результаты**.
Учебные баллы не подтверждают квалификацию; эффективность требует апробации.
