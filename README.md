# Я — специалист

Игра-симулятор о первых шагах в профессии: от выпускного до первого рабочего дня.
Продукт образовательного проекта ГБПОУ «Челябинский радиотехнический техникум»,
автор сценария — Ганеева Индира Ринатовна.

## Рамки

| Решение | Значение |
|---|---|
| Сервер | нет. Статичная сборка, прогресс в браузере |
| Статистика прохождений | не собирается |
| Звук | нет ни музыки, ни звуков интерфейса |
| Фоны | анимированный SVG, рисуем сами; растровые картинки из PDF не используются |
| Портреты | параметрический SVG, 7 персонажей × 5 эмоций |
| Стиль интерфейса | «комикс»: пузыри с хвостом, контуры 3px, жёсткие тени, растр, жёлтый и красный, Rubik. Наброски направлений — `design/mocks/` |
| Платформы | десктоп, телефон, проектор |

## Структура

```
content/         весь текст игры, редактируется без программиста
  characters.json    персонажи и параметры их портретов
  specialties.json   специальности → фильтр вакансий и наборы тестов
  vacancies.json     10 вакансий сцены 3
  tests.json         4 набора тестовых заданий сцены 4
  achievements.json  достижения
  backgrounds.json   локации и их анимации
  scenes/            сцены 00–07 в порядке прохождения
  schema/            описание форматов
docs/
  scenario-original.txt   исходный текст сценария из PDF, без правок
  changes.md              что и почему изменено относительно оригинала
  pitch.html              план разработки и арт-байбл
assets/reference/         портреты и фоны из PDF — только как референс
tools/validate.mjs        проверка контента
```

## Запуск через Docker Desktop (Windows)

Установите и запустите Docker Desktop с Linux containers.
Скачайте репозиторий через GitHub → Code → Download ZIP и распакуйте его.
Откройте терминал в папке, где находится `compose.yaml`, и выполните:

```bash
docker compose up --build -d
```

Откройте http://localhost:8080 — игра работает, пока запущен Docker Desktop.
Node.js на компьютере устанавливать не нужно.

Остановить игру:

```bash
docker compose down
```

После обновления исходников снова выполните `docker compose up --build -d`.
Сборка Docker проверяет контент и TypeScript, затем собирает игру.
Прогресс хранится в браузере. В контейнере работает только статический веб-сервер.

## Запуск без Docker

Полная инструкция по размещению на сайте и дальнейшей работе — [DEPLOY.md](DEPLOY.md).

```bash
npm install
npm run dev
```

Сборка для сайта техникума — `npm run build`, готовые файлы появятся в `dist/`.
Пути относительные, поэтому папку можно положить в любой раздел сайта.

## Проверка

```bash
npm run check
```

Сначала `tools/validate.mjs` читает все файлы `content/`, проверяет структуру,
ссылки между сценами, существование персонажей и специальностей, корректность
вариантов ответа в тестах и то, что секретное слово действительно встречается
в описании вакансии. Затем `tsc --noEmit` проверяет типы. Зависимостей у
валидатора нет — он запускается и без `npm install`.

## Стек

Vite + TypeScript, без UI-фреймворка. Портреты и локации — SVG, который
собирается кодом из данных, растровых файлов в игре нет. Прогресс хранится
в `localStorage`, сервера и сбора статистики нет.

## Ход работ

Этапы и критерии готовности — в `docs/pitch.html`.

- [x] **00 — Препродакшн.** Сценарий в JSON, правки применены, валидатор проходит.
- [x] **01 — Ядро новеллы.** Движок сцен, главное меню, две локации, портреты
      с эмоциями, сохранение. Пролог и сцена 1 проходятся целиком; экраны
      следующих этапов показывают честную заглушку и пропускаются.
- [x] **02 — Конструктор резюме.** Форма из сценария рядом с живым документом,
      счётчик заполнения, выбор специальности в профиль, печать и PDF.
- [x] **03 — Доска вакансий и отклики.** Десять карточек, полные описания, гейт
      отклика: ловушки, мошенники, специальность, секретное слово.
- [x] **04 — Тестовые задания.** Письмо, четыре набора по специальности,
      провал возвращает к вакансиям.
- [x] **05 — Собеседование.** Пять вопросов, итог по большинству, петля
      «Новые попытки».
- [x] **06 — Трудовые отношения.** Карточки знаний, две папки договоров,
      мини-тест с разбором ошибок, таблица итогов.
- [x] **07 — Первый день и финал.** Задание по специальности, достижения,
      финальная таблица, «Пройти заново».
- [x] **08 — Арт.** Семь анимированных SVG-локаций, портреты 7 × 5 эмоций.
- [x] **09 — Полировка и запуск.** Телефон, клавиатура, сборка, интерфейс
      «комикс», инструкция по развёртыванию. Осталось за техникумом: выложить
      сборку на сайт и провести пилот с группой.
